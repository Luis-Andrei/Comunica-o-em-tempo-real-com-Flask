# Chat em Tempo Real com Flask e Socket.IO

Este é um projeto de chat em tempo real desenvolvido com Flask e Socket.IO.

## Funcionalidades

- Chat em tempo real
- Interface simples e intuitiva
- Mensagens instantâneas
- Design responsivo

## Requisitos

- Python 3.x
- Flask
- Flask-SocketIO
- Python-SocketIO
- Python-EngineIO

## Instalação

1. Clone o repositório:
```bash
git clone https://github.com/Luis-Andrei/Comunica-o-em-tempo-real-com-Flask.git
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

## Executando o Projeto

1. Execute o servidor:
```bash
python app.py
```

2. Acesse o chat em seu navegador:
```
http://localhost:5000
```

## Estrutura do Projeto

- `app.py` - Arquivo principal da aplicação
- `templates/index.html` - Template HTML do chat
- `requirements.txt` - Dependências do projeto
